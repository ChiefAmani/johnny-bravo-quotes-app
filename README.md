# Johnny Bravo Quotes App

## Whoa, Mama! Get Your Daily Dose of Johnny Bravo!

This is a fun, retro-styled web application dedicated to serving up classic Johnny Bravo catchphrases. Built with pure HTML, CSS, and JavaScript, it's a single-page app designed for simplicity and quick deployment.

## Features

*   **Over 50 Classic Quotes:** A collection of Johnny's most memorable lines.
*   **Random Quote Generator:** Click a button to get a fresh dose of Bravo wisdom.
*   **Search & Filter:** Easily find specific quotes by typing keywords.
*   **Copy to Clipboard:** Click on any displayed quote to instantly copy it.
*   **Quote Counter:** Keep track of how many quotes are currently available.
*   **Retro 90s Styling:** Yellow and black color scheme, bold fonts, and fun animations reminiscent of the classic cartoon era.
*   **Fully Mobile Responsive:** Looks great on any device, from desktop to mobile.
*   **Zero Dependencies:** A single `index.html` file, making it incredibly easy to deploy.

## Deployment to GitHub Pages

This app is designed to be deployed as a static site directly to GitHub Pages. Follow these simple steps:

1.  **Fork this Repository:** If you want your own copy to modify, fork the `ChiefAmani/johnny-bravo-quotes-app` repository to your GitHub account.

2.  **Clone the Repository (Optional):** If you want to work on it locally, clone your forked repository:
    ```bash
    git clone https://github.com/YOUR_USERNAME/johnny-bravo-quotes-app.git
    cd johnny-bravo-quotes-app
    ```

3.  **Push to GitHub (if not forked):** If you created a new repository, ensure `index.html` and `README.md` are in the root of your `main` branch.

4.  **Enable GitHub Pages:**
    *   Go to your repository on GitHub.
    *   Click on the **"Settings"** tab.
    *   In the left sidebar, click on **"Pages"** under the "Code and automation" section.
    *   Under "Build and deployment", for "Source", select **"Deploy from a branch"**.
    *   For "Branch", select `main` (or your primary branch) and choose the `/(root)` folder.
    *   Click **"Save"**.

5.  **Access Your Site:** GitHub Pages will build and deploy your site. This usually takes a few minutes. Once deployed, your app will be accessible at `https://YOUR_USERNAME.github.io/johnny-bravo-quotes-app/`.

    *Note: Replace `YOUR_USERNAME` with your actual GitHub username.*

## Technologies Used

*   **HTML5:** For the structure of the web page.
*   **CSS3:** For styling and retro aesthetics.
*   **JavaScript (ES6+):** For interactive features like random quotes, search, and copy to clipboard.
